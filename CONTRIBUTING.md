# Участие в разработке

Спасибо за интерес к Metuur. Перед отправкой изменения:

1. Создайте отдельную ветку от `main`.
2. Выполните `gofmt -w .`.
3. Запустите `go test -count=1 ./...` и `go vet ./...`.
4. Проверьте сборку на Windows:
   `go build -buildvcs=false -trimpath -o .\bin\metuur.exe .\cmd\metuur`.
5. В pull request кратко объясните проблему, решение и способ проверки.

Новые подсказки должны использовать реальные файлы и модули открытого проекта,
не придумывать несуществующие цели и иметь тест на ранжирование.

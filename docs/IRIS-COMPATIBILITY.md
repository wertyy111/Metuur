# Проверка совместимости с IRIS

Проверено 31 июля 2026 года по официальному репозиторию
[versenilvis/IRIS](https://github.com/versenilvis/IRIS).

- IRIS опубликован под лицензией
  [BSD Zero Clause (0BSD)](https://github.com/versenilvis/IRIS/blob/main/LICENSE).
  Она разрешает использование, копирование, изменение и распространение кода
  для любых целей, с оплатой или без неё.
- Metuur не включает бинарные файлы IRIS и не заявляет совместимость или
  официальную связь с его автором. Название и оформление проекта отличаются.
- На момент проверки среди Go-файлов Metuur и IRIS не найдено ни одного
  побайтово одинакового файла. Metuur использует собственную реализацию Windows
  Console API, PowerShell-сессии, анализа VS Code и локального интерпретатора.
- Упоминание IRIS в README означает только источник вдохновения и даёт понятную
  атрибуцию, хотя лицензия 0BSD её не требует.

Итог: лицензия IRIS разрешает даже копирование, а фактическая реализация Metuur
самостоятельна, поэтому заметного риска нарушения авторских прав исходным кодом
не обнаружено. Это техническая проверка, а не индивидуальная юридическая
консультация.

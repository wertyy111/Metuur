# История изменений

## 0.3.1 — 2026-07-31

- исправлен ввод с клавиатуры во встроенном терминале VS Code;
- `ENABLE_VIRTUAL_TERMINAL_INPUT` больше не конфликтует с чтением событий Windows Console;
- добавлен тест конфигурации сырого режима консоли.

## 0.3.0 — 2026-07-31

- интерфейс приближен к IRIS: логотип `METUUR` встроен в верхнюю рамку,
  выровнены колонки и обновлена фиолетово-мятная палитра;
- README использует настоящий скриншот пользователя, текстовый макет удалён;
- добавлены асинхронные AI-подсказки через OpenAI-совместимый API;
- локальный провайдер по умолчанию — переносимый llama.cpp с `Qwen2.5-Coder-0.5B-Instruct`;
- реализованы debounce, отмена устаревших запросов и неблокирующий интерфейс;
- AI получает активный файл VS Code, структуру Go-модуля, git status и историю;
- модель выбирает только из безопасных команд, построенных по реальным файлам проекта;
- добавлены автоматическая установка модели, выбор диска и команда `metuur ai suggest`;
- добавлены `metuur ai setup` и расширенная диагностика `metuur ai status`.

## 0.2.1 — 2026-07-31

- MIT заменена на Metuur Free Use — No Sale License 1.0;
- бесплатное использование, изменение и распространение разрешены;
- продажа исходников, бинарников и изменённых копий запрещена;
- коммерческое использование Metuur как инструмента остаётся разрешённым.
- добавлено обязательное уведомление автора перед публичной публикацией форка;
- добавлен CODEOWNERS для проверки всех изменений владельцем;
- добавлен полностью офлайн-интерпретатор намерений для русских и английских
  фраз, опечаток и текста в неверной раскладке;
- добавлено адаптивное ранжирование команд по текущей папке;
- добавлен настоящий снимок интерфейса в README.

## 0.2.0 — 2026-07-31

- проект получил имя Metuur;
- добавлены готовые Go-команды сразу после ввода `go`;
- добавлено автоматическое определение активного файла VS Code;
- все подсказки привязаны к найденным файлам, пакетам и модулям;
- добавлены прокрутка полного каталога и строгая фильтрация целей;
- исправлены ввод интерактивных программ и сообщения об ошибках;
- добавлены автоматический запуск и задачи VS Code.

# История изменений

## 0.4.0 — 2026-08-02

- отдельный Metuur REPL заменён настоящим PowerShell внутри Windows ConPTY;
- ввод переведён на raw VT byte stream и прозрачную передачу каждой обычной клавиши;
- интерактивные `go run`, `Read-Host`, отладчики и Ctrl+C работают внутри одной shell-сессии;
- интерфейс перенесён на структуру modern overlay IRIS: responsive 76-column box,
  6 строк, ghost text, `▶`, scroll counter и `<Tab> Accept • <Ctrl+R> Mode`;
- `Tab`, `Enter`, `Shift+Tab`, `Esc`, `Ctrl+R` и стрелки приведены к поведению IRIS;
- `Esc` больше не передаётся в `PSReadLine` и не очищает настоящую строку;
- `Ctrl+A`, `Ctrl+E` и `Ctrl+W` получили одинаковые PowerShell-привязки в 5.1/7;
- добавлена задержка неоднозначного `ESC`, поэтому разделённые VT-стрелки не печатают `[A`;
- устранено starvation зависание после закрытия канала асинхронной модели;
- вставка строки совместима с Windows PowerShell 5.1 и pwsh 7 без Unix Ctrl+U binding;
- добавлен полный E2E-тест `VS Code ConPTY → Metuur → PowerShell → интерактивный stdin`;
- активный `.go`-файл читается из локального состояния VS Code без изменения
  каталога пользовательских расширений; bridge оставлен только явной опцией;
- overlay больше не создаёт строки и не прокручивает терминал; ввод и курсор
  остаются видимыми, а prompt использует стандартный Unicode-символ `☭`;
- Nerd Font icons выключены по умолчанию, поэтому в обычном шрифте Windows нет
  квадратов с вопросительным знаком;
- проект теперь честно обозначен как неофициальная производная Windows-адаптация IRIS;
- добавлены точный upstream commit, 0BSD и third-party notices.

## 0.3.4 — 2026-08-01

- автоматические подсказки переведены в неблокирующий inline-режим без рамки;
- `Tab` принимает лучший вариант, `Enter` принимает и запускает безопасную команду;
- полный список открывается только явно через `Ctrl+Space` или стрелки и закрывается при продолжении ввода.

## 0.3.3 — 2026-08-01

- чтение клавиатуры вынесено в отдельный блокирующий поток Windows Console;
- главный цикл одновременно принимает клавиши и результаты локальной модели;
- чтение приостанавливается перед запуском команды, поэтому интерактивные Go-программы получают клавиатуру напрямую.

## 0.3.2 — 2026-08-01

- устранена остановка чтения клавиатуры после появления AI-подсказки в VS Code;
- ожидание ConPTY заменено на безопасный неблокирующий опрос очереди событий;
- Metuur автоматически восстанавливает сырой режим, если терминал его сбросил.

## 0.3.1 — 2026-07-31

- исправлен ввод с клавиатуры во встроенном терминале VS Code;
- `ENABLE_VIRTUAL_TERMINAL_INPUT` больше не конфликтует с чтением событий Windows Console;
- добавлен тест конфигурации сырого режима консоли.

## 0.3.0 — 2026-07-31

- интерфейс приближен к IRIS: логотип `METUUR` встроен в верхнюю рамку,
  выровнены колонки и обновлена фиолетово-мятная палитра;
- README использует настоящий скриншот пользователя, текстовый макет удалён;
- добавлены асинхронные AI-подсказки через OpenAI-совместимый API;
- локальный провайдер по умолчанию — переносимый llama.cpp с `Qwen2.5-Coder-0.5B-Instruct`;
- реализованы debounce, отмена устаревших запросов и неблокирующий интерфейс;
- AI получает активный файл VS Code, структуру Go-модуля, git status и историю;
- модель выбирает только из безопасных команд, построенных по реальным файлам проекта;
- добавлены автоматическая установка модели, выбор диска и команда `metuur ai suggest`;
- добавлены `metuur ai setup` и расширенная диагностика `metuur ai status`.
